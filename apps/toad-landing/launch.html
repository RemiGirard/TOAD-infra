Launch validation record

Updated 2026-10-28. This page separates implementation, local checks, recorded production acceptance, and outstanding live work. No outside-user onboarding or adoption study has been performed.

Implemented

  • Allow-listed source publication with a returned immutable image digest.
  • First-app, update, rollback, encrypted-secret, and CI recipes.

No CA was generated or rotated during this launch.

The tracked CLI, workflows, and guides are the source of truth for this launch. The scheduled GitHub probe checks the public project URL and requires its TOAD-specific response marker. Consult GitHub Actions for its latest run result.

Remaining recovery gate

Review the concrete drill plan, then run the disposable recovery drill with an isolated context, stack, project/zone, and exact dataset approved by the operator. Record a real application data assertion, measured RPO/RTO, offsite backup verification, and a test notification to the intended operator destination.

The live production stack is not a recovery-drill target. Destruction, volume restore, CA rotation, node reboot, and parent-DNS changes need exact target authorization. A published landing page does not satisfy this gate.
