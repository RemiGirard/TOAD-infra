DOMAIN

The name people type

A domain is a name you control, such as example.com. Your app can use an address below it, such as hello.platform.example.com. Buying a name does not buy a server.

UNDER THE HOOD

Four tools.
One understandable setup.

Each tool has a clear job. Git keeps the desired state; the TypeScript CLI coordinates provisioning, configuration, deployment, and verification.

WHAT YOU GET

Useful guardrails.
Visible tradeoffs.

For developers who want to own the setup.

TOAD provisions Infomaniak resources and configures Swarm, HTTPS, metrics, logs, and admin access. Application manifests enforce pinned images, resource limits, and rollback policies. JSON diagnostics give your assistant something concrete to inspect.

Initial cloud setup still needs credentials and DNS configuration. Three managers protect control-plane quorum; they do not replicate local app data. Traefik runs one replica, and stateful services need an explicit recovery plan.
